# New Life Dental Clinic — Demo Website

A modern, responsive demo website for a dental clinic, built with **React 19**, **Vite**, and **Tailwind CSS v4**. This is a frontend-only design preview created to demonstrate the visual direction and user experience for a real client project.

> **Status:** Demo / Preview — not for production use.  
> **Purpose:** Client evaluation before full-stack build.

---

## 📸 Preview

A single-page, scrollable marketing site featuring:

- **Hero section** with live availability badge and dentist profile card
- **Trust strip** highlighting clinic credentials
- **Services grid** with hover-lift interactive cards
- **About section** introducing the dentist
- **Patient testimonials** with star ratings
- **Appointment booking form** (UI only — no backend in this demo)
- **Dark footer** with contact details and demo watermark

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Framework | React 19 |
| Build Tool | Vite 7 |
| Styling | Tailwind CSS v4 (`@tailwindcss/vite` plugin) |
| Fonts | Inter (body), Plus Jakarta Sans (display) |
| Hosting | Vercel |

**Note on Tailwind v4:** This project uses the new v4 architecture — no `tailwind.config.js`, no PostCSS config. All theme customization lives in `src/index.css` inside the `@theme` block.
